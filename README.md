# AIGES — интерактивное коммерческое предложение

Next.js App Router, React, TypeScript, CSS Modules, Framer Motion. Одна страница с 12 разделами, локальными шрифтами и медиа. Внешние CDN во время просмотра не требуются.

## Запуск

Требуется Node.js 20.9+.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:3000.

```sh
npm run lint
npm run typecheck
npm run build
npm run start
```

Для публикации использовать Node.js-хостинг с поддержкой Next.js. `npm run build` создаёт production-сборку; в настройках хостинга задать `next start --hostname 0.0.0.0` и домен `proposal.aiges.kz`. Публикация на существующий домен из этой рабочей папки не выполнялась.

## Контент и компоненты

- `src/content/content.ts` — тексты, направления, отрасли, решения, стек, проекты, цены и контакты.
- `src/components/hero-film.tsx` — обложка и видео. Видео включается без звука при появлении в экране, при уходе из экрана или скрытии вкладки ставится на паузу. При reduced motion автозапуск выключен; доступен ручной запуск.
- `src/components/sections.tsx` — остальные информационные разделы.
- `src/components/projects.tsx` — горизонтальная галерея. Стрелки, клавиатура, Home/End, перетаскивание мышью, колесо, trackpad и нативный touch swipe. На краях галереи вертикальная прокрутка продолжается.
- `src/components/navigation.tsx` — индикатор активного раздела без нумерации.
- `src/components/deck.module.css` — сетка, адаптивность и стили.
- `src/app/globals.css` — брендовые переменные, включая утверждённый акцент `--aiges-blue: #2F5BFF`.

## Источники

PNG 27–37 из предоставленных материалов — композиции, тексты, руки, QR-код и шесть изображений проектов. Текст в браузере остаётся HTML, целые слайды не используются вместо интерфейса.

С опубликованной `https://proposal.aiges.kz/` сохранены исходные `assets/logo.svg`, `assets/intro.mp4`, `assets/poster.jpg`, `assets/page-1.jpg`. Архитектурная графика извлечена из правой части последнего изображения, где нет текста. Контакты Telegram и WhatsApp взяты из `sourceLinks` опубликованной страницы; адрес email не придуман и не показан.

Onest поставляется локально с лицензией OFL. Карта создана в SVG из географических данных world-atlas / Natural Earth; линии показывают регионы работы, а не офисы или подтверждённых клиентов.

Изображения проектов извлечены из общего слайда и имеют ограниченное исходное разрешение. Для максимально чёткой полноэкранной демонстрации их можно заменить в `public/assets/project-*.webp` на оригинальные скриншоты.

В контенте оставлены TODO для спорного текста технологического раздела, грамматики исходного блока о команде и неподтверждённых метаданных проектов. Годы, результаты проектов и отдельные URL кейсов не выдуманы.

## Проверка в браузере

При запущенном production-сервере:

```sh
npx playwright install chromium
npm run test:browser
npm run test:a11y
```

Проверяются размеры 1920, 1440, 1280, 1024, 768, 430, 390; изображения; аккордеоны; видео; навигация; галерея и reduced motion. Скриншоты и отчёт сохраняются в `test-results/` (не входят в git). `TEST_URL` позволяет задать адрес другого сервера.

Автоматическая проверка доступности axe выполняется для desktop и mobile. Акцентный цвет `#2F5BFF` применяется к ссылкам, линиям, кубикам и кнопкам. Подписи над заголовками и служебная нумерация удалены; в подвалах разделов используется изображение логотипа из презентации. Кубики добавлены только в четыре направления.

Повторная подготовка графики при наличии исходных PNG:

```sh
node scripts/prepare-assets.mjs "C:/path/to/aigesnew"
```
